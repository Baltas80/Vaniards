# Android release checklist

## Build target

- [ ] Android target API 36 or higher
- [ ] Compatible GDevelop Android export toolchain
- [ ] Unique application/package ID
- [ ] Version name set to the intended release
- [ ] Version code incremented for every Play upload
- [ ] Release signing configured and backed up securely

## Device QA

- [ ] Fresh install
- [ ] Launch and main menu
- [ ] Touch controls
- [ ] Movement and combat
- [ ] Pause/resume
- [ ] Audio
- [ ] Screen scaling/orientation
- [ ] Back button behavior
- [ ] App restart
- [ ] No blocking crashes

## Google Play

- [ ] Signed AAB generated
- [ ] Internal/closed testing upload
- [ ] Store listing
- [ ] App icon and screenshots
- [ ] Content rating
- [ ] Data safety declaration
- [ ] Privacy policy if required by the final data practices
- [ ] Target API verification
- [ ] Production rollout
