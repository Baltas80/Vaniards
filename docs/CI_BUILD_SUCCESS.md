# Vaniards Android CI build

## Successful build

GitHub Actions run **#8** completed successfully.

Run:
https://github.com/Baltas80/Vaniards/actions/runs/35539661614

Artifacts:
- `Vaniards-touch-1.0.1-debug.apk`
- `Vaniards-1.0.1-unsigned.aab`

The APK is an Android debug build for physical-device testing. It is not the final Google Play package.

The AAB generated by CI is unsigned. The workflow now supports signing when the following GitHub Actions secrets are configured:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

The signing key must remain under the developer's control and must never be committed to the repository.

## Test gate still required

The new APK must be installed on a real Android device and the following checked:
- touch left/right
- jump
- attack
- dash
- menu touch
- English default
- Spanish selection
- landscape layout
- audio
- resume/restart

Only after this device QA should the signed AAB be submitted to a Google Play testing track.
