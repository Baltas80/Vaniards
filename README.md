# Vaniards

**Vaniards** is a 2D action-platformer made with GDevelop.

## Android build

- **App name:** Vaniards
- **Android package:** `com.baltas80.vaniards`
- **Version:** 1.0.1
- **Orientation:** landscape
- **Languages:** English (default), Spanish
- **Controls:** keyboard, gamepad and mobile touch controls
- **Target API:** Android 16 / API 36 or higher

## Source in this repository

The complete editable GDevelop project is stored under `game/source/` as numbered source parts because the GitHub connector cannot upload the large binary asset tree directly.

GitHub Actions reassembles the exact project into `game/Vaniards.json` during the build and recovers the referenced game assets from the existing APK stored in this repository.

The source configuration includes:

- Touch left/right movement.
- Touch jump, attack and dash.
- Touch menu navigation.
- English default + Spanish.
- Mobile runtime resolution adaptation.
- Android package ID `com.baltas80.vaniards`.
- Anonymous GDevelop metrics event removed.

## Automated Android build

Workflow: `.github/workflows/android.yml`

On every push to `master` and on manual dispatch, GitHub Actions:

1. Reassembles and validates the GDevelop JSON.
2. Recovers the game resources from the reference APK.
3. Uses GDevelop 5.6.282 to export the game to HTML5.
4. Wraps the export in Cordova Android 15.1.0.
5. Builds an installable debug APK.
6. Attempts a release AAB build; a signing key is required for the final Play Store AAB.
7. Uploads the Android artifacts to the workflow run.

## Google Play

The final Play Store upload must be a **signed AAB**, not the debug APK.
